# Garage: Bad Dream Adventure — русификатор

Неофициальная русская локализация для Windows-версии **1.1.270**, Steam build **20618823**.

## Скачать

Откройте **Releases** и скачайте `Garage_RU_1.1.270_v0.9.0.zip`. Архивы `Source code`, которые GitHub создаёт автоматически, не являются установщиком русификатора.

## Установка

1. Закройте Garage.
2. В Steam откройте «Управление → Просмотреть локальные файлы».
3. Распакуйте папку `Garage_RU_1.1.270` рядом с `Garage.exe`.
4. Запустите `Install.cmd` внутри папки русификатора.
5. Запустите игру через Steam и выберите «Русский» в настройках языка (бывший English).

Python и OpenSSL не нужны. Установщик проверяет совместимость, сохраняет оригиналы в `Garage_RU_backup_v1` и позволяет восстановить их через `Restore.cmd`. `Check.cmd` проверяет файлы без установки. Вложенную папку `Garage_Data` вручную поверх игры не копируйте.

## Содержание

Переведены 2465 непустых записей основной локализации, диалоги и сюжетные ветки, меню, предметы, письма, дневники, справки и подсказки управления. Добавлена кириллица оригинального угловатого шрифта. Для длинного текста используется PT Serif Caption. Переведены восемь типов табличек интерфейса.

Часть надписей внутри иллюстраций остаётся оригинальной. EGO/FUEL с японскими обозначениями сохранены по художественному решению. Ранее сохранённые записи журнала могут оставаться на прежнем языке.

## Статус 0.9.0

Предварительный выпуск. Автоматические проверки структуры ресурсов, управляющих команд, тегов, установки и отката пройдены. Визуальная проверка переноса на Steam 1.1.270 и полное прохождение всех веток ещё не завершены. Другие версии игры не поддерживаются этим пакетом.

Сохранения, EXE, DLL и Steam-библиотеки не меняются. После обновления игры может понадобиться новый выпуск перевода. Не обходите проверку совместимости.

## Авторы

Игра и оригинальные материалы: SAKUBA Tomomi, SmokymonkeyS. Неофициальная локализация Askent с использованием ИИ-инструментов Codex/imagegen. PT Serif Caption — ParaType, SIL OFL 1.1; текст лицензии включён в архив.

Для использования требуется собственная копия Garage. Сообщая об ошибке, приложите скриншот, имя персонажа и текст реплики.
